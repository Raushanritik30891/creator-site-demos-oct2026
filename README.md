# Creator Site Demos — October 2026

Ten tailored, independent creator website concepts for Indian gaming YouTubers. Each creator gets a different colour system, layout direction, channel-specific modules, and a CTA to their public YouTube channel/business contact.

## Preview locally
Open `index.html` and choose a creator. Individual pages are in their own directories.

## Important
These are static frontend concepts, not finished production websites. The pages do not connect to YouTube APIs, store enquiry forms, provide analytics, booking, CMS, admin access or automated messages. Any unverified metrics or sample content should not be published as factual. Creator-approved copy, assets and actual video links must be collected before launch.
